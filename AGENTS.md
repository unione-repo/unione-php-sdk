# AGENTS.md

UniOne PHP SDK — client for the UniOne transactional email Web API (Web API 1.90).

## Working on this repository

- **Generated code.** The whole package is generated by the UniOne team from the UniOne Web API OpenAPI spec (Web API 1.90): sources, docs, README.md and this file. Do not hand-edit it: the next release replaces the content of this repository. Report problems and requests in the issues of this repository (https://github.com/unione-repo/unione-php-sdk).
- **Build and check:**

  ```bash
  composer validate
  composer install
  ```

- **Source label.** Every request carries the query parameter `platform=php-sdk.2.1.3`, added in one place, the shared request client (`ApiClient`); a package built on this SDK puts its own label in front: `<package>.<version>,php-sdk.2.1.3`.
- **Tests.** Before a release the generator builds and lints the package and runs every example of docs/ and of this file against a mock of the API: no real API key, no real sends.
- **Release.** The version (2.1.3 in composer.json) and the tag `v2.1.3` come from the generator; README.md states the Web API version the release was generated from.
- **Secrets.** Never commit API keys; the examples read `UNIONE_API_KEY` from the environment.

## Integrating UniOne with this SDK

Full quickstart: [README.md](README.md). Install:

```bash
composer require unione-repo/unione-php-sdk
```

Requirements: PHP 8.1+.

If the project is built on one of these frameworks, install its package instead: it brings this SDK and plugs it into the framework (configuration, client in the container, mailer, webhooks).

| Framework | Package | Guide |
|---|---|---|
| Laravel | `unione-repo/unione-laravel` | [AGENTS.md](https://github.com/unione-repo/unione-laravel/blob/HEAD/AGENTS.md) |
| Symfony | `unione-repo/unione-symfony-bundle` | [AGENTS.md](https://github.com/unione-repo/unione-symfony/blob/HEAD/AGENTS.md) |

Rules that generated code must follow:

- Server-side only. Read the API key from `UNIONE_API_KEY`; never put it in browser or mobile code, never commit it.
- Base URL `https://api.unione.io/en/transactional/api/v1` (an account registered on another host uses that one: `eu1.unione.io`, `us1.unione.io`); every method is POST with a JSON body; auth header `X-API-KEY`. The SDK does all of it.
- First email without DNS: `domain/get-sandbox-domain` → `confirmed-email/create` (the user clicks the link within 48 hours) → `email/send` from `noreply@<sandbox-domain>` to the confirmed address. Account API key only; up to 10 confirmed addresses, 100 emails a day; the domain expires after 31 days.
- Never ship a sandbox domain as the production sender (it is not in `domain/list`); read `from_email` from config. Production needs a verified domain: `domain/get-dns-records` → DNS records → `domain/validate-verification-record`, `domain/validate-dkim` → `domain/list`.
- Set `message.idempotence_key` on retryable sends; retry network errors, `429` and `5xx` with backoff, not other errors unchanged. Up to 500 recipients and 10 MB per request, each attachment up to 7 MB; always `body.html` or `body.plaintext`.
- Delivery events via webhook (`webhook/set`) with a fast, idempotent HTTPS handler, not polling; check the `auth` field of every notification: the MD5 of the request body with the `auth` value replaced by the API key.
- Keep the default unsubscribe and tracking behaviour; changes go through UniOne support.
- Do not invent methods or fields. Check [docs/](docs/) of this package, the [API reference](https://docs.unione.io/en/web-api-ref) or [llms.txt](https://docs.unione.io/llms.txt).

### Send an email

The client reads the API key from `UNIONE_API_KEY`:

```php
<?php

use UniOne\Api\Email\Model\EmailSendRequest;
use UniOne\Api\Email\Model\MessageObject;
use UniOne\Api\Email\Model\MessageObjectRecipientsItem;
use UniOne\Client\ApiException;
use UniOne\Common\Model\BodyObject;
use UniOne\UniOne;

$client = UniOne::client(getenv('UNIONE_API_KEY'));

try {
    $response = $client->email()->send(new EmailSendRequest(
        message: new MessageObject(
            recipients: [
                new MessageObjectRecipientsItem(
                    email: 'user@example.com',
                    substitutions: [
                        'CustomerId' => '12452',
                        'to_name' => 'John Smith',
                    ],
                ),
            ],
            body: new BodyObject(
                html: '<b>Hello, {{to_name}}</b>',
                plaintext: 'Hello, {{to_name}}',
            ),
            subject: 'UniOne test email ',
            fromEmail: 'email@example.com',
            fromName: 'John Smith',
        ),
    ));
    echo $response->jobId, PHP_EOL;
} catch (ApiException $e) {
    echo $e->getErrorCode(), ': ', $e->getMessage(), PHP_EOL;
}
```

### Errors

Every method throws `UniOne\Client\ApiException` when the request fails: the HTTP status (0 for a network error or a timeout), the [API error code](https://docs.unione.io/en/web-api-ref#api-errors) and the message.

```php
// $client created as above
try {
    $client->system()->ping();
} catch (\UniOne\Client\ApiException $e) {
    // getHttpStatus() is 0 for a network error or a timeout
    error_log($e->getHttpStatus() . ' ' . $e->getErrorCode() . ' ' . $e->getMessage());
}
```
